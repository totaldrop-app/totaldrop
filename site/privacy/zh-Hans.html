隐私政策 · 第 7 版 · 2026 年 11 月 8 日

我们不收集任何关于你的信息。

TotalDrop 没有账号、没有统计分析、没有广告，也没有崩溃报告。本页准确说明你传输文件时我们的服务器能看到什么，以及这些信息多快就会消失。

我们是谁

TotalDrop 是一个由 Ozan Özdil 维护的免费开源项目。本政策适用于 TotalDrop 应用、命令行客户端以及 totaldrop.app 上的服务器。联系方式：privacy@totaldrop.app。

应用收集什么

什么也不收集。应用不会询问你的姓名、电子邮件地址或电话号码，也不包含任何跟踪、统计分析、广告或崩溃报告代码。在 0.3.0-beta.2 及之前，Android 应用只需要访问互联网。之后的版本只请求传输所需的权限：访问互联网和网络状态，用于建立连接；在后台运行传输，让你切换到其他应用时传输仍能继续；以及显示通知，用于传输进行时那条带“停止”按钮的常驻通知。这些权限只留在你的设备上，不会向我们或任何其他人发送任何内容。

你的文件

当两台设备能够互相连通时，文件直接从一台设备传到另一台；否则经由我们的中继服务器（见下文）。无论哪种方式，文件都经过端到端加密。我们的服务器永远看不到你的文件、文件名或内容，也无法读取经过它们的数据：密钥只存在于这两台设备上。

会合服务器能看到什么

开始传输时，两台设备都会连接到我们运行在 Cloudflare 上的会合服务器 rendezvous.totaldrop.app。它帮助持有同一个代码的两台设备找到彼此。在此过程中，它必然会看到：

  • 每台设备的 IP 地址，任何互联网服务器都能看到；
  • 代码开头的数字（例如 7-harbor-rocket 中的 7），但永远看不到单词；
  • 你连接的时间，以及两台设备之间交换的简短消息的大小。从第三条消息起，这些消息都经过加密，只有另一台设备能读取。

服务器不会把以上任何内容写入日志。一个信箱及其中的所有内容会在两台设备都离开后立即删除，最迟在一小时后删除。每次传输结束后，代码中的数字会停用 10 分钟才再次分配；代码尝试失败后则停用 24 小时。为了限制滥用，服务器还会统计每个 IP 地址打开的连接数（对 IPv6 而言，是地址的前 64 位）。这些计数只保存在内存中，并以一个用随机密钥从地址派生出的代码（而不是地址本身）来标识，每个计数最迟在其最后一次连接约两分钟后被遗忘，并且从不写入磁盘或日志。

Cloudflare 作为我们的基础设施提供商，会依照其自身的隐私政策处理 IP 地址，以提供和保护服务。中继服务器同样如此。我们已为这两台服务器关闭了请求日志和 Workers 日志记录。

寻找直连路径

为了跨互联网连接，每台设备会先询问一台 STUN 服务器，自己是以哪个公网 IP 地址和端口出现的。默认使用 Cloudflare 的免费 STUN 服务 stun.cloudflare.com。它和任何互联网服务器一样能看到你的 IP 地址，除此之外什么也看不到。在隐私模式（见下文）下，设备不会询问它。

中继服务器能看到什么

当两台设备无法直接连通时，由我们运行在 Cloudflare 上的中继服务器 relay.totaldrop.app 承载传输。在 Android 和 Linux 0.2.0-beta.1 及以后的版本中，以及自 2026 年 10 月 29 日起从代码仓库构建的命令行中，只有当两台设备开始连接约 1.2 秒后仍未选定直连时，设备才会联系中继服务器。如果任一设备处于隐私模式，或另一台设备没有通告任何地址，设备会立即联系中继服务器。及时选定直连的传输只有在该连接之后变得静默时才会到达中继服务器：在 0.3.0-beta.3 之后的 Android 和 Linux 版本及其附带的命令行中，设备若因网络中断或另一台设备暂停而在直连上 8 秒内没有收到另一台设备的任何数据，就会把传输转到中继服务器。只有另一台设备仍在通过直连发送时，传输才会转回直连；否则会一直留在中继服务器上，直到传输结束。只有两台设备使用同一个中继服务器时才会这样。如果之后才选定直连，设备会在那一刻关闭与中继服务器的连接。较旧的版本（Android 0.1.0-beta.5、Linux 0.1.0-beta.4）会在每次传输开始时连接中继服务器，而这些版本的接收设备会使用发送方指定的任何中继服务器；请更新以避免这种情况。使用中继服务器时，它能看到：

  • 每台设备的 IP 地址；
  • 为这一次传输专门生成、之后永不再用的两个随机密钥；
  • 每台设备连接和断开的时间，以及经过的加密数据量。

密钥不会把一次传输与另一次关联起来，但你的 IP 地址可能会：中继服务器和会合服务器都由我们在 Cloudflare 上运行，它们会在相隔片刻之内看到这个地址。中继服务器无法读取文件、文件名或任何关于你身份的信息。它不写任何日志，传输结束后也不保留与该传输有关的任何内容。

每台设备的中继服务器地址会以加密方式告知另一台设备。如果发送方使用自己的中继服务器（命令行的 --relay 选项或 TOTALDROP_RELAY），在 0.2.0-beta.1 及以后的版本中，接收设备只有在该服务器同时也是接收方自己设置的中继服务器时才会使用它；否则绝不会联系它。任何运行设备所连接的中继服务器的人，都能看到上面列出的信息。如果两台设备使用不同的中继服务器且没有直连路径，传输会报错停止。

隐私模式（自 0.2.0-beta.1 起位于应用“设置”中的“向对方设备隐藏我的地址”，命令行中为 --relay-only）：你的设备不向另一台设备通告任何 IP 地址，不询问 STUN 服务器，从不直接连接另一台设备，即使来自已配对设备的直连也会拒绝。每次传输都经过中继服务器，因此无论你是发送还是接收，另一台设备都不会得知你的 IP 地址。这样速度较慢，而且中继服务器和会合服务器仍能看到你的 IP 地址。无论你是发送还是接收，另一台设备都必须与你使用同一个中继服务器（所有应用都使用我们的）；否则传输会报错停止。

另一台设备能看到什么

为了直接连接，两台设备会以加密方式互相交换各自的网络地址。因此，与任何直连一样，每台设备都会得知对方的本地和公网 IP 地址。处于隐私模式的设备不通告任何地址，因此另一台设备不会得知它的地址。

在你的设备上

收到的文件在 Android 上保存在 Download/TotalDrop，在 Linux 上保存在 ~/Downloads/TotalDrop。它们是普通的共享文件，与你的其他下载文件一样处理。从 Android 发送时，你选中的文件会被复制到应用的缓存中。当你关闭已完成的发送或停止一次发送时，这些副本会被删除。选中但未发送的文件（你在发送前返回、将它们从列表中移除，或 Android 关闭了应用）的副本可能会保留，直到之后的某次发送被关闭或停止，或直到 Android 清理缓存。应用保存两项设置：会合服务器的地址，以及隐私模式是否开启（在 Linux 上位于 ~/.config/totaldrop/settings.toml）。Android 应用自身的数据，即这些副本和设置，永远不会进入云备份或设备间的数据迁移。

儿童

TotalDrop 并非面向儿童，也不向任何人收集个人数据。

你的权利

除上文所述、几分钟内即消失的短时计数外，我们不保存任何关于你的个人数据，因此没有可供查阅、更正或删除的内容。如有问题或投诉，请写信至上方地址。你也有权向数据保护监管机构投诉。

变更

第 7 版说明，会合服务器为限制滥用，会在内存中对每个 IP 地址的连接作短时计数；它能看到的内容没有变化。第 6 版对应 0.3.0-beta.3 之后的 Android 和 Linux 版本，其中变得静默的直连会转到中继服务器，因此中继服务器可能看到一次从直连开始的传输。第 5 版列出了 0.3.0-beta.2 之后的 Android 版本所请求的权限，这些权限让传输能在后台继续并显示通知；我们的服务器能看到的内容没有变化。第 4 版跟随 Android 和 Linux 0.2.0-beta.1，这两个版本改变了中继服务器和另一台设备能看到的内容。在这些版本中，设备不再在每次传输开始时联系中继服务器，而只在未能及时选定直连或没有可尝试的直连路径时才联系。接收方不再使用仅由发送方选择的中继服务器，因此隐私模式现在也会隐藏接收方的地址。隐私模式现在也出现在应用的“设置”中，并拒绝直连。第 4 版还说明了 Android 应用在缓存中保留什么。第 3 版更正了第 2 版：第 2 版称应用只在所有直连路径都不可用时才连接中继服务器（实际上当时它们在每次传输开始时就会连接），并称隐私模式会隐藏接收方的地址（当时并不会）。第 3 版还列出了 Linux 应用的文件。第 2 版加入了 STUN 服务和中继服务器。为之后版本计划的功能（链接、可选的匿名账号）将改变我们的服务器所处理的内容。在任何此类功能发布之前，我们都会更新本政策，并在项目的公开代码仓库中保留每一个版本。
