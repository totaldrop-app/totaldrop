Why TotalDrop

  • Nothing is uploaded

    Files go from your device to theirs. No copy waits on a company's server, and no link expires in a week.

  • No account, ever

    No email, no phone number, no sign-up. A short code is all two devices need.

  • Every platform, one app

    Android, Linux and the command line today; Windows, macOS and iOS on the way. Phone to laptop, any brand to any brand.

  • No size limit from us

    Whole folders, long videos, original-quality photos. Only your disk and your connection set the limit.

  • Verified, not trusted

    Four words on both screens prove nobody is in the middle. Encryption is end to end and post-quantum.

  • Free and open, for good

    Open source under the GPL, paid for by donations. No ads, no tracking, no premium tier.

Three steps

  1. Choose files

    Any type, as many as you like. The receiver gets only what you chose.

  2. Share the code

    A number and two words, like 7-harbor-rocket. It works once and then expires.

  3. Compare four words

    Both screens show the same four words. If they match, the connection is yours alone.

Across the internet, the two devices connect directly wherever they can. When a router or firewall is in the way, the encrypted transfer goes through our relay, which cannot read it.

Only you and the receiver can open it

Encrypted before it leaves
Files are encrypted on your device and decrypted only on the receiver's. The keys never exist anywhere else.
The code cannot be guessed offline
The code turns into a key through a PAKE handshake, so a wrong guess fails at once and the attempt is burned. Key exchange includes post-quantum ML-KEM.
Our server only introduces
It sees your IP address and the code's number, never the words, the file names or the files. It keeps no logs.
Code anyone can check
Every line is public. Version 1.0 ships only after an independent security audit.
