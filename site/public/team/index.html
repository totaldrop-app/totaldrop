How the work is checked

  • Every change starts as a public issue and reaches the app only through a pull request.
  • Each pull request passes the automated checks and a review by someone, or an AI agent, that did not write it.
  • Only the maintainer merges, releases and deploys. Releases are built by GitHub Actions, never on a personal computer.
