How the work is checked

  1. Everyday changes start as a public issue and reach the app only through a pull request.

  2. Each pull request passes the automated checks and a review by a person or an AI agent that did not write it.

  3. Only the project lead merges, releases and deploys. Releases are built by GitHub Actions, never on a personal computer.
