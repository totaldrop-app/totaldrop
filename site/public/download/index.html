Check what you install

  • Get TotalDrop only from Google Play, from this page or from the project's GitHub releases. We do not publish anywhere else.
  • On Linux, install the file you downloaded with sudo pacman -U, sudo apt install ./ or sudo dnf install ./ and its name.
  • Every release on GitHub lists SHA-256 checksums. Compare them before you run a file.
  • Everything is built from the public source code, which you can read and build yourself.
