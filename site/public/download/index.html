What's new

Android 0.3.0-beta.7

  • Share files to TotalDrop from any app, such as Gallery or Files. Holding the app icon offers Send, Receive and Send clipboard.
  • Send a text: type it, share it from another app, or pick "Send with TotalDrop" on selected text. A text that arrives is shown, not saved, and can be copied.
  • The heading above the verification words fits on narrow screens.
  • Your phone no longer connects to a relay the other device will not use.

Linux 0.3.0-beta.6

  • Send a text. "Send text" on the Send screen, or "Send clipboard" in the app's launcher menu, which opens Send with the clipboard's text filled in. A text that arrives is shown, not saved, with any hidden characters named, and "Copy text" copies it exactly as it came. On the command line: totaldrop send --text "…", or totaldrop send - for the text on standard input.
  • Send from your file manager. "Send with TotalDrop" in the right-click menu of Dolphin, Nemo and Files (once nautilus-python is installed), for any local files and folders. Right-click TotalDrop in the taskbar or app launcher for "Send files", "Receive files" and "Send clipboard". The file-manager menus are not in the Flatpak: a sandboxed app cannot add to another program's menus.
  • Flatpak. A Flatpak package for x86-64 and ARM64, which installs without touching the system, also where the system is read-only. It reaches the network, ~/Downloads/TotalDrop, the files you pick, desktop notifications, Hyprland's socket and your desktop's theme files (read only), and nothing else of your home folder.
  • Your language, everywhere. Software centres such as Discover and GNOME Software describe TotalDrop in all 35 languages of the app. With Qt 6.11 or later, the right-click menu of text fields is in the app's language, and Qt's own windows follow right-to-left languages. Settings says that codes and verification words stay in English, so that two devices set to different languages show the same words.
  • Security. A sending device no longer connects to its relay when the receiving device uses a different relay or none, so that relay no longer sees the sender's IP address; a receiver on 0.1 set to another relay now needs a direct path. On the command line, control characters in an error's detail, which can come from the other device or a server, are named instead of passed to the terminal (GHSA-c6jh-7p7q-8gg4).

Check what you install

  • Get TotalDrop only from Google Play, from this page or from the project's GitHub releases. We do not publish anywhere else.
  • On Linux, install the file you downloaded with sudo pacman -U, sudo apt install ./ or sudo dnf install ./ and its name.
  • A Flatpak installs without sudo: flatpak install --user ./totaldrop-*.flatpak
  • Every release on GitHub lists SHA-256 checksums. Compare them before you run a file.
  • Everything is built from the public source code, which you can read and build yourself.
